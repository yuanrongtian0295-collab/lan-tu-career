# 篮途 · 王朝人生

移动端优先的职业篮球人生文字模拟游戏。项目包含开局建模、球星天赋抽取、选秀、82场赛季、关键回合、伤病、交易、徽章、奖项、关系剧情、社交平台、自动生成新秀、跨赛季成长与退役人生。

## 运行

```bash
npm install
npm run dev
```

生产检查：

```bash
npm test
npm run build
```

## 主要入口

- `src/data/playerLibrary.ts`：现役/历史赛季模板、属性模型和跨位置继承
- `src/engine/rookieGenerator.ts`：可复现的未来新秀生成
- `src/engine/gameEngine.ts`：上场时间、比赛与统计模拟
- `src/engine/careerState.ts`：存档、赛季、关系、徽章、奖项和跨年状态
- `src/screens/`：建模、首页、比赛、生涯、联盟、手机、球员与退役页面
- `docs/concepts/`：实现使用的三张视觉概念稿

## 数据与授权

内置球员赛季评分为本游戏独立研发模型，不是官方 NBA 2K 数据。私人本地版本包含真实球员姓名、30 支 NBA 球队名称和从 NBA 官方 CDN 下载到本地的球队徽标，不包含真实球员照片。若公开或商业发行，仍需为真实球员姓名、肖像、联盟/球队商标和正式统计数据取得适用授权。游戏引擎和授权数据层已分离，可替换数据源而无需重写生涯系统。
