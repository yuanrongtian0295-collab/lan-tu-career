# 球员数据库与动态联盟系统

## 数据范围

- 5,955 个 NBA 球员身份，使用 NBA `PERSON_ID` 作为首选主键。
- 591 名 2025-26 现役名单球员，覆盖 30 支球队。
- 27,342 份历史赛季/生涯球员卡，按年代拆分为 7 个延迟加载文件。
- 每份可比赛球员卡包含 28 项游戏能力、总评、潜力、原型、代表能力、徽章等级和基础赛季数据。

`public/data/nba` 是完整离线数据库；`src/data/generated/currentPlayers.json` 是创建存档时同步加载的紧凑现役快照。游戏运行时不会访问第三方数据服务。

## 存档级动态

存档版本 4 新增 `LeagueState`。每个新存档生成独立种子，同一存档可复现，不同存档会产生不同的球员状态和发展结果。

每个比赛日会推进：

1. 全联盟轮换球员的出场时间与个人数据。
2. 体能、健康、士气和近期状态。
3. 按年龄、耐久、负荷和疲劳计算的伤病及恢复。
4. 伤病后的轮换重排与球队实力、节奏重算。
5. MVP、DPOY、最佳新秀等竞争者更新。

每个休赛期会推进：

1. 年龄曲线、隐藏发展倾向、潜力空间和随机波动共同决定成长/衰退。
2. 老将退役、非核心球员交易、重伤跨赛季恢复。
3. 自动生成新秀加入战绩较差的球队并参与后续轮换。

## 数据更新与验证

```bash
npm run sync:players
npm run validate:players
npm test
npm run build
```

同步脚本会缓存原始快照、重建当前名单与历史分片，并覆盖前端内置快照。验证脚本检查身份/赛季数量、30 队覆盖、ID 唯一性、28 项属性完整性和评分边界。

## 评分声明

能力与徽章是根据公开比赛数据推导的本游戏独立评分，并非 NBA 2K 官方评分。历史早期数据缺少现代追踪项目时，会使用生涯资料和同年代百分位估计；每张卡的 `dataConfidence` 字段记录估计可信度。
