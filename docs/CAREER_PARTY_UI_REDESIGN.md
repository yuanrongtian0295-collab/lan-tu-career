# 生涯派对全局 UI 重设计规范

## 目标

除已经确认的生涯页外，首页、比赛、手机、球员、联盟、休赛期、奖项、退役与建模流程全部迁移为同一套蓝白黄街球派对系统。只重做表现层，不修改比赛、剧情、存档或球员数据库结构。

## 全局视觉令牌

- 深海军蓝：`#08123A`，页面底色、底栏与深色信息面板。
- 钴蓝：`#0D47FF`，页面结构、主边框和标题背景。
- 皇家蓝：`#1669FF`，次级结构和交互状态。
- 电光青：`#00C5FF`，进度、正向反馈、焦点描边。
- 活力黄：`#FFD400`，唯一主操作与选中状态。
- 珊瑚红：`#FF4D4F`，仅用于伤病、危险、负向数值。
- 纯白：`#FFFFFF`，主要内容底色；搭配极淡蓝点阵纹理。
- 深蓝正文：`#071849`；辅助正文：`#516181`。

## 统一组件

- 页面标题：白色重磅斜体，深蓝硬投影，配少量青黄速度线。
- 信息面板：白色点阵纸面、2px 蓝色斜切边框、青色角部切口。
- 胶囊切换器：白底蓝边；选中态黄色或皇家蓝；全局只保留这一套结构。
- 主按钮：黄色斜切运动按钮；次按钮：青蓝按钮；危险按钮：珊瑚红。
- 状态标签：青色收益、黄色注意、红色风险、浅灰中性。
- 数值条：深蓝文字、蓝青进度，关键目标可用黄色已完成段。
- 列表与表格：白色连续信息面，不使用层层嵌套卡片。
- 底部导航：统一高度、图标尺寸、字号与选中态；深蓝底，选中项黄色。
- 动效：面板入场 180–260ms；主操作轻微压缩；模拟中使用青色扫描与呼吸光；禁用时不闪烁。

## 推荐实施顺序

1. 抽取全局颜色、字体、面板、按钮、胶囊切换器与底栏组件。
2. 首页迁移，统一人物主视觉、资源条、数值条、比赛入口和动态列表。
3. 比赛中心迁移，覆盖赛前、直播、暂停、数据、阵容、伤病与终场状态。
4. 手机和球员页迁移，优先保障长文本与高密度数据可读性。
5. 联盟、奖项和休赛期迁移，统一表格与排行榜。
6. 建模和退役页迁移，最后完成全流程视觉回归。

## 验收

- 375 / 390 / 430px 无横向滚动。
- 正文不低于 12px，主要操作不低于 14px，触控高度不低于 44px。
- 所有动态文字为代码渲染，不嵌入贴图。
- 所有页面只使用一套胶囊切换器、一套底栏、一套主次按钮状态。
- 现有游戏逻辑测试、存档兼容和事件结算全部保持通过。
