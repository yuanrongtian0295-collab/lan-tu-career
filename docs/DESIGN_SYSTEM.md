# 篮途视觉系统

概念稿：`concepts/home-dashboard.png`、`concepts/talent-draw.png`、`concepts/live-game.png`。

## 视觉原则

- 碳黑 `#070806` 作为真实主背景，不使用偏灰卡片墙。
- 象牙白 `#F2EAD8` 负责高层级文字；冠军金 `#D8B05D` 只表示价值、荣誉和主操作；电光青 `#20C9E8` 表示实时、能量和选择状态。
- 页面采用开放式分隔线、赛场信息带和编辑排版，不使用通用 Bento 网格。
- 中文界面优先使用苹方/微软雅黑系统字体，品牌字使用系统楷体回退。
- 触控目标最小42px；底部导航兼容 iOS safe-area。

## 动效

- 页面切换：180ms 位移淡入。
- 底部导航：弹簧式选中位移与共享指示线。
- 数值条：弹簧式宽度增长。
- 剧情弹层：底部弹簧进入。
- 所有动画尊重 `prefers-reduced-motion`。
