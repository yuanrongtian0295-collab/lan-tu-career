# V3 三渲二涂鸦 UI 设计规范

## 视觉概念

以“地下球馆里的球星生涯剪贴簿”为核心：3D 球员采用赛璐璐分层光影和粗墨轮廓，界面叠加战术箭头、马克笔圈画、喷漆、半调网点、撕纸与运动胶带。整体成熟、锋利、商业化，不做儿童卡通。

## 色彩

- 背景：沥青黑 `#080909`、炭灰 `#151716`
- 正文：骨白 `#F4F0E6`
- 主要操作：安全橙 `#FF5A12`
- 数据与进行中：电光青 `#00C8EF`
- 成功或特别提示：酸性绿 `#B7F300`
- 风险与伤病：医疗红 `#ED382F`
- 荣誉：奖杯金 `#E5B84C`

## 组件语言

- 页面保持无设备外框的移动端全屏布局。
- 使用开放式信息带、撕纸分区、列表和日历，不使用通用圆角卡片网格。
- 主按钮像宽幅喷漆标语；次按钮使用粉笔描边和手绘角标。
- 已完成赛程使用降饱和、低亮度和 W/L 印章。
- 风险必须以红色概率章显示，收益使用青色或绿色数值标签。
- 正式 UI 文字、球队 Logo、数据和按钮全部由 React/CSS 原生实现；球员画面和纸张纹理作为独立美术资产。

## 页面设计稿

1. `01-builder.png`：完整建模、风格选择与 24 点分配。
2. `02-home.png`：优化首页、球员主视觉、下一场和模拟入口。
3. `03-calendar.png`：82 场日历、暗格和一键模拟结果。
4. `04-game-story.png`：实时比赛、带伤决定、战术和风险剧情。
5. `05-phone-social.png`：联系人、师徒课程、社交发布与舆论。
6. `06-player-badges.png`：训练负荷、详细属性、徽章和人生方向。
7. `07-league-library.png`：联盟排名、真实球星库和新秀生成。
8. `08-offseason-retirement.png`：休赛期选择与第二人生结局。

## 动效方向

- 页面切换：撕纸横移与 180ms 墨迹擦除。
- 属性增长：数值翻牌后出现短促马克笔上划。
- 剧情出现：底部纸张弹入，风险章延迟 120ms 盖下。
- 模拟赛季：当前格青色圈画，完成后压暗并盖 W/L 印章。
- 徽章升级：金属徽章先转半圈，再出现喷漆粒子。
